# 存储与生命周期

r[storage-lifetime.define]

## 1. 定义

在Pxc中，一个对象可以以值对象，托管对象，以及指针上的不安全对象存储，并遵循各自的生命周期。对象本身的类型，与其存储的位置并没有关系。

> [!EXAMPLE]
>
> 以下代码示例中，同时声明了一个值对象，托管对象，以及一个堆指针上的对象
>
> ```pxc
> Foo a := Foo(1); // 构造一个值对象，其生命周期在作用域后结束
> dyn b := Foo(2); // 构造一个托管对象，其生命周期将在GC分析不可达后结束
> Foo* c := Allocate<Foo>(1); // 分配一块堆空间，并得到指针
> ConstructAt(c,3); // 在堆空间上构造一个对象，其生命周期需要等到手动调用DestroyAt(c);
> ```
